# Weather App

A weather application that allows users to search for weather information based on city name or coordinates, view current weather conditions, and check a 5-day forecast. The app also supports temperature unit switching (Celsius and Fahrenheit) and dark/light mode.

## Features

- **Search for City**: Search weather information by entering a city name.
- **Search by Coordinates**: Get weather details by entering geographic coordinates (latitude and longitude).
- **Current Location**: Automatically detect and display weather for the user's current location.
- **Celsius and Fahrenheit Switch**: Toggle between Celsius and Fahrenheit temperature units.
- **Dark and Light Mode**: Switch between dark and light themes for the user interface.
- **Humidity, Wind Speed, Clouds, Visibility**: View detailed weather indicators including humidity, wind speed, cloud coverage, and visibility.
- **5-Day Forecast**: View a 5-day weather forecast showing the highest and lowest temperatures, with a line chart for temperature trends.
- **Caching**: Caches weather data for 60 seconds to optimize performance and reduce API calls.
